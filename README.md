# WSKIData Downloads

Öffentliche Installationsdateien und Versionsinformationen für WSKIData. Der Quellcode und Clubdaten sind nicht Teil dieses Repositories.

Downloadseite: https://grubekla.github.io/wskidata-downloads/

Die iOS-IPA ist unsigniert und muss mit Sideloadly signiert und installiert werden. Die bestehende App nicht vorher löschen; bei Updates dieselbe Apple-ID und App-Kennung verwenden.

Für neue Versionen zuerst die geprüfte IPA als Release hochladen, anschließend die Downloadseite und `latest.json` aktualisieren. Der Versionshinweis erscheint nur für eine höhere Version oder Buildnummer. Ein Android-Eintrag wird erst bei einem verfügbaren Android-Release ergänzt.

Im Feld `downloadPage` bei jeder Veröffentlichung die Buildnummer im Query-Parameter `?v=BUILD` aktualisieren, damit der Update-Knopf keine ältere gecachte Downloadseite öffnet.
